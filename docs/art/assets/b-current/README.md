## 2. B01 수술 기록 — 귀·배 통일 (2026-08-21) ✅

`B01_idle` 만 **구 split 판본**에서 왔고 나머지 14종은 잎귀 통일본이라, 정체성 요소 두 개가 어긋나 있었다.
**Idle은 화면에 가장 오래 떠 있는 프레임**이라 그대로 두면 idle ↔ 다른 포즈 전환마다 귀 모양과 배가 바뀐다. 수술로 맞췄다.

| 부위 | 수술 전 | 수술 후 |
|---|---|---|
| **귀** | 잎 두 장이 겹친 **갈라진 귀** | `B02_sit` 의 잎귀를 이식 — **한 장짜리 잎 + 잎맥 하이라이트** |
| **배** | 배가 전부 초록(크림 패치 없음) | **크림 배 추가** (`#e9e1b1`, 왼쪽 한 칸 `#c1bc8d` 음영) |
| 눈 | 탁한 갈색 덩어리 7x7 | `B02_sit` 눈 블록 이식 (3절) |

**★ 귀 이식이 가능했던 이유: `B01` 의 머리는 `B02` 의 머리를 x축으로 1px 옮긴 것과 같다.**
머리 영역 645px 중 593px이 완전히 일치한다 — 즉 두 그림은 **머리를 공유하고 귀만 다르게 그린 것**이다.
그래서 `B02` 를 +1,0 으로 옮겨 **cols 0~27 / rows 0~32 구간만 통째로 덮어썼다.** 머리 오른쪽(턱선)은 두 포즈가 달라서 건드리지 않았다.

**배는 이식이 아니라 그려 넣은 것이다.** `B01` 은 서 있고 `B02` 는 앉아 있어 몸통이 다른 그림이다(서 있는 통일본 `B06`·`B09` 와도 일치율 16%).
몸통 초록 연결요소를 잡고 그 안에 타원을 교차시켜 칠했다. **행마다 몸통 중심을 지나는 구간 하나만 남겨야 한다** — 안 그러면 팔·다리로 새고, 다리 사이 검은 선이 배 한복판에 구멍처럼 남는다(실제로 밟았다).

⚠️ **아직 남은 차이: `B01` 에만 갈색 주머니가 있다** (몸통 왼쪽 아래). 다른 포즈에는 없다.
`B07_handover` 가 같은 주머니를 손에 들고 있으므로 **소품일 가능성**이 있어 지우지 않고 뒀다. 판단 필요.

## 3. 눈 규격 ★

**검은 구체 + 작은 크림 하이라이트 + 아래쪽 갈색 크레센트.** 기준 파일은 `B02_sit.png`.
크기까지 규격이다 — 눈 하나가 대략 **9x10 px**.

- `B01_idle` 은 원래 눈이 **탁한 갈색 덩어리 7x7** 이었다. 2026-08-21에 `B02_sit` 의 눈 블록을 그대로 이식해 색·구조·크기를 맞췄다.
- **흰자위 + 검은 동공 분리는 위반이다.** 생성 모델은 「놀람·크게 뜬 눈」 지시를 받으면 반드시 이렇게 그린다(`B13_startled` 이 그 상태로 남아 있다) → **표정 극단값은 생성 대신 수작업 수정**한다.

## 5. Idle 애니메이션 — `anim/idle/` ✅ (2026-08-21 확정)

```
b-current/anim/idle/
├── B_idle_0~3.png          ← 호흡 4프레임 (f0 = B01_idle 원본과 픽셀 동일)
├── B_idle_blink_1~2.png    ← 깜빡임 (f1·f2 위상에 대응)
└── B_idle_preview.gif      ← 컨펌본 미리보기 (4x, 140ms)
```

**AI 생성 아님.** `poses/B01_idle.png` 픽셀을 좌표만 옮긴 것이다 — 3절 눈 규격과 잎귀를 지키려면 이 방법밖에 없다. 재생성은 `tools/b-anim/build-idle.mjs`.

**★ 이 스프라이트는 y축으로 깨끗하게 갈린다** — 이게 공정 전체의 근거다.

| 행 | 내용 |
|---|---|
| `y 0~11` | 귀 끝만 |
| `y 0~33` | 귀 + 머리 **전부** (목도리·몸통 한 픽셀도 안 섞임) |
| `y 34~54` | 목도리 + 몸통 + 꼬리 + 팔 |
| `y 55~60` | 다리·발 (두 다리는 y=55부터 갈라짐) |

**★ 규칙 1 — 레이어는 아래로만 움직인다.** 위로 올리면 머리 밑변(y=33)과 몸통 윗변(y=34) 사이에 **1px 구멍**이 뚫린다. `머리 이동량 >= 몸통 이동량` 이 코드에 잠겨 있다. 그래서 **머리가 늦게 따라오는 체인은 못 만든다** — 머리를 더 크게 움직여서 리드시킨다.

**★ 규칙 2 — 다리는 덮지 말고 압축한다.** 몸통을 내려 다리를 덮으면 하필 `y=55~56`(두 다리 사이가 갈라진 **유일한** 줄)이 지워져서 다리가 통짜가 된다. 다리 구간은 `55=56`, `57=58`, `59=60` 으로 같은 줄이 두 번씩이므로 **중복 줄만 뺀다**.
- 1px ↓ → `56` 삭제 / 2px ↓ → `56`·`58` 삭제 → **발과 다리 갈라짐은 항상 남는다**

**프레임별 이동량 (px)**

| 부위 | f0 | f1 | f2 | f3 |
|---|--:|--:|--:|--:|
| 머리+귀 `y0~33` | 0 | 1 | 2 | 1 |
| 귀 끝 x축 `y0~11` | 0 | 0 | -1 | -1 |
| 몸통+꼬리 `y34~54` | 0 | 1 | 1 | 0 |
| 꼬리 끝 추가 `y≤44 ∩ x≤20` | 0 | 0 | +1 | +1 |

**깜빡임** — 눈 검은 덩어리를 연결요소로 뽑아 바로 위 머리 초록으로 메우고, 높이 55% 지점에 2px 눈꺼풀 선(`#151d06`, 양끝 `#263515`)을 얹는다. ⚠️ **평평한 직선이어야 한다** — 위로 휜 아치는 `B06_laugh` 의 웃는 눈이라 깜빡일 때마다 B가 웃는다.

**인게임**: `Art/Characters/B/Sprites/` 에 동일 6장, `B_Idle.anim` 12키프레임(호흡 3사이클 + 3번째에 깜빡임, 1.54초 루프).
⚠️ **씬 Animator 는 아직 꺼져 있다** — `B_Sleep` 이 죽은 참조라 켜면 B가 사라진다 (`B_Walk` 는 6절에서 복구됨).
