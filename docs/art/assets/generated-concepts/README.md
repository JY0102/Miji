# Generated Concept Asset Layout

Generated concept images are grouped by what they represent, not by generation date.

## Folders

- `characters/A/` — A / Player robot concept references
- `characters/B/` — B / organic wanderer concept references
- `characters/balancer/` — base Balancer references
- `characters/balancer/variants/selected/` — Balancer variants the user kept as useful directions
- `characters/balancer/variants/rejected/` — Balancer variants kept for audit/history but not used as direction
- `characters/inhabited-objects/` — other inhabited object character concepts
- `characters/collapsed/` — collapsed wanderer/enemy character concepts
- `maps/awakening-cave/` — awakening cave map/room concepts
- `maps/balancer-route/` — Balancer route or confrontation-area concepts
- `maps/first-play-area/` — early play/tutorial area concepts
- `maps/scar-of-legend/` — lore/scar area concepts
- `maps/woven-nest/` — woven-nest area backgrounds and map concepts
- `world/architecture-signatures/` — reusable architecture language comparisons
- `world/tech-level/` — world technology-level comparison images

## Rules

- Do not keep new generated concepts directly in this root folder.
- Put character art under the character it depicts.
- Put map/background art under the map, area, or gameplay location it depicts.
- Keep rejected exploration images if they explain a decision; move them to a `rejected/` folder instead of deleting them.
