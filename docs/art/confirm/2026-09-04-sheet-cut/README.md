## 파이프라인 (스크립트: 세션 스크래치패드 `cut_and_compose2.py`, Python/Pillow)

2. 6x4 셀 분할 → 알파 bbox로 트림 → `props/` 24조각, `terrain/` 24조각
3. 조각 내부에 갇힌 흰 포켓은 중성 흰색 키잉(min≥230, 채도 스프레드≤14)으로 제거 — 랜턴의 따뜻한 발광은 스프레드가 커서 보존됨
4. `mockup_sheetcut_v2_1672x941.png` = 배경 + 지면 캡 스트립 + 부유 플랫폼 2 + 프랍 9점 합성

## 의미 — 접근 전환

- Wang 반복 타일(PixelLab)로 지형 비주얼을 만들던 접근을 **모듈 지형 조각 방식(할로우나이트식)**으로 전환할 근거.
  큰 조각을 손으로 얹고 충돌은 투명 콜라이더 — 기존 레이어 계약("레이어는 비주얼 전용")과 일치.
- 분업 확정: 배경·지형 조각·프랍 원판 = ImageGen 시트 / 컷·정리 = 스크립트 / 캐릭터·애니메이션·소형 스프라이트 = PixelLab.

## 남은 작업 (채택 시)

- 시트 2(석재 캡)·시트 3(덩굴 지형)도 동일 컷 적용
