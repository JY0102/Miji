# B Village Production Kit v2 — Reference-specific

사용자 제공 이미지 세 장을 서로 섞지 않고, 각 이미지의 재질과 구조 언어를 살린 고밀도 픽셀 제작 키트다. 3번 이미지만 1·2번의 밝은 세이지·셀라돈·청록 색감에 맞춘 뒤 같은 보정본에서 타일과 프랍을 파생했다.

## 요청 대응

| 레퍼런스 | 제작 범위 | 기준 |
|---|---|---|
| 1 — 밝은 거목·단차 룸 | 지형 타일 24종 + 배경 전용 플레이트 | 이끼 낀 뿌리/토양 플랫폼, 넓은 안개 숲 |
| 2 — 거목 다리 마을 | 지형 타일 24종 | 나무 판재·거목 기둥·로프/덩굴 하부 구조 |
| 3 — 뿌리 여관 | 밝은 색감 보정본 + 지형 타일 24종 + 프랍 24종 | 원래 토폴로지와 생활감 유지, 1번 팔레트로 통일 |

## 공통 규격

- 장면 네이티브: 832×468 PNG, 미리보기 1664×936.
- 타일·프랍 네이티브: 768×512 PNG, 미리보기 1536×1024.
- 타일·프랍 배열: 6열×4행, 24개 모듈/오브젝트.
- 픽셀 처리: nearest-neighbor, 디더링 없음, 최대 64 opaque colors.
- 알파: 투명/불투명 0 또는 255만 사용하며 반투명 픽셀은 없다.
- 충돌 표현: 걷기·착지 상단은 수평, 벽타기 면은 수직. 곡선은 밑면·천장·비등반 외벽·장식에 집중한다.

## 시트 구성

### 1번 지형

- 수평 착지면 6종.
- 거목 수직면·좌우 끝단·안쪽 코너.
- 바닥/천장 접합, 버트레스, 뿌리 아치.
- 덩굴·이끼·잔뿌리 비충돌 하부 오버레이.

### 2번 지형

- 반복 가능한 판재형 수평 발판과 좌우 캡.
- 굵고 좁은 거목 기둥, 벽 가장자리.
- 판재-거목 접합과 지지 구조.
- 로프, 덩굴, 잎사귀, 매달린 뿌리 하부 오버레이.

### 3번 지형·프랍

- 지형: 뿌리/석재 수평길, 트렁크 벽, 플랫폼 접합, 뿌리 아치, 계단, 유기적 밑면.
- 조명: 매달린 등불, 포드 등불, 화로, 벽등, 원형 창, 등불 브래킷.
- 건축: 엮은 차양, 매달린 바구니 발판, 로프 난간, 뿌리 계단, 타원형 문틀, 포드 집.
- 생활/식생: 벤치, 공동 테이블, 바구니, 항아리, 허브 걸이, 조리 도구, 버섯·갈대·이끼·덩굴·뿌리 장식.

## 생성 메타데이터

- 스타일 프레임워크: `architecture-space` case 331 + `scene-storytelling` case 330.
- ImageGen 분류: 타일·프랍 `style-transfer`, 1번 배경 `background-extraction`, 3번 색감 교정 `lighting-weather`.
- 3번 보정 원칙: 구조·출구·가구·등불 배치를 유지하고 전체 팔레트만 1번의 64색 앵커에 매핑했다.
- 체크무늬처럼 구워진 중성 배경과 접촉 그림자는 후처리에서 제거했다.

## 사용 주의

현재 타일·프랍 시트는 모듈 선택과 실제 제작을 위한 고밀도 컨셉 키트다. 6×4 배열과 분리는 명확하지만, Unity 자동 슬라이스용 32×32 정본 아틀라스로 바로 간주하지 않는다. 채택 항목을 정한 뒤 셀 크기, 피벗, 타일 접합선, 콜라이더 기준선을 별도로 보정한다.
