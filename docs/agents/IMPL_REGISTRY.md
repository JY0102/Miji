# Implementation Agent Registry

기능 구현 에이전트 목록입니다.
새로운 기능 구현을 시작할 때 여기에 먼저 등록합니다.

---

## 등록 형식

```
### [IMPL-XXX] [기능 이름]
- **상태**: 계획 중 / 진행 중 / 완료 / 보류
- **담당 파일**: `src/...`
- **연관 기획 문서**: `docs/planning/...`
- **설명**: (이 에이전트가 구현하는 기능 요약)
- **시작일**: YYYY-MM-DD
- **완료일**: YYYY-MM-DD 또는 미정
```

---

## 활성 에이전트

> 등록된 구현 에이전트가 없습니다.
> 기능 구현 시작 시 이 파일에 먼저 항목을 추가합니다.

---

## 완료된 에이전트

> 없음
