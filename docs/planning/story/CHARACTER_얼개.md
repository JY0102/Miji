# 캐릭터 설정 — 얼개 (Ulgeh, 관찰자)

**분류:** 주인공 로봇 1 (매개체 탑승 몸체)
**참조:** `docs/superpowers/specs/2026-07-24-story-character-design.md` (§2 로봇 1 — 관찰자)

---

## 개요

- **성격:** 분석적, 철학적. 세계와 자신을 끊임없이 관찰하고 질문함
- **대화 스타일:** "우리 안의 것은 무엇인가. 왜 우리만 이것을 가지는가."
- **행동 방식:** 상황을 먼저 파악하고 움직임
- **이름의 유래:** '얼개' = 구조/틀. 관찰자가 세계와 자신의 '얼개(구조)'를 분석하려는 성격과 직결
- **영문 표기: Ulgeh** (표준 로마자 Eolgae 대신 채택 — "-gae"가 영어권에서 "-gay"로 오독되는 것을 피하기 위한 발음 우선 스펠링)

## 매개체 갈등과의 연결

- `docs/planning/story/CHARACTER_매개체.md`의 "살(피부) vs 기계의 마음" 갈등 중, **기계적 명료함** 쪽에 가까운 순간을 외면화하는 역할.
- 관찰자에 탑승 중일 때는 매개체가 "확신하고 싶다"는 갈망 쪽으로 기우는 연출 가능 (세부 연출은 레벨/대사 기획 단계에서 결정).

## 미확정 항목

- 각성 초기 코드명
- 이름을 얻는 구체적 대사/연출 (수행 로봇과의 대화 중, 폐허 구역)
