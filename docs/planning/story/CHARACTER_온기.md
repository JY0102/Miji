# 캐릭터 설정 — 온기 (Ongi, 행동가)

**분류:** 주인공 로봇 2 (매개체 탑승 몸체)
**참조:** `docs/superpowers/specs/2026-07-24-story-character-design.md` (§2 로봇 2 — 행동가)

---

## 개요

- **성격:** 즉흥적, 직관적. 생각보다 행동이 먼저
- **대화 스타일:** "생각은 나중에. 지금은 앞으로."
- **행동 방식:** 일단 움직이고 이후에 판단
- **이름의 유래:** '온기' = 따뜻함. 감정이 앞서고 즉흥적인 행동가의 생동감과 직결

## 매개체 갈등과의 연결

- `docs/planning/story/CHARACTER_매개체.md`의 "살(피부) vs 기계의 마음" 갈등 중, **생물체적 충동/감각** 쪽에 가까운 순간을 외면화하는 역할.
- 온기에 탑승 중일 때는 매개체가 "느끼고 싶다"는 갈망 쪽으로 기우는 연출 가능 (세부 연출은 레벨/대사 기획 단계에서 결정).

## 미확정 항목

- 각성 초기 코드명
- 이름을 얻는 구체적 대사/연출 (모험가 생물체가 붙여줌, 생물체 구역)
