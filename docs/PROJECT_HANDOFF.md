## ⚠️ 2026-07-30 세계관 전면 리부트

**기존 세계관·스토리·메카닉이 전부 폐기되었다.**

폐기된 것 — 매개체(Medium), 얼개·온기, 사람=창조자, 로봇 vs 생명체 전쟁, 분류 실패, 스왑, 순간이동 앵커, 자율 이동, MVP 4구역 맵, 주요 NPC(모험가 생물체·수행 로봇).

폐기 이유 — **메카닉에 스토리를 맞춘 결과물이었다.** 스왑을 먼저 만들고 매개체를 사후 정당화하는 식이라 이야기가 아니라 변명문이 되어 있었다. 새 원칙은 **세계를 먼저 만들고 메카닉은 거기서 나온다**.

## 새 세계관 — 확정된 것

전체는 `docs/superpowers/specs/2026-07-30-mind-economy-worldbuilding-design.md` 참조.

### 세계의 법칙

1. **정신력의 총량은 고정되어 있다.** 신앙이 아니라 확인 가능한 사실
2. 새 생명체가 태어날 때 총량에서 **일정량이 배분**된다
3. **죽으면 전부 반환된다. 단 강제 회수는 불가능하다** — 산 개체에게서 억지로 빼낼 수 없다
4. **한 개체가 담을 수 있는 양에 상한(그릇)이 있다.** 넘으면 **고장 난다**
5. 정신은 원래 **생명체에만** 깃든다

### 앎의 값 — 이 세계관의 핵심

> **앎이 늘어날수록 붕괴한다.** 잃어서가 아니라 그릇을 넘어서려 하기 때문이다.

붕괴자는 흔하다. 대부분 같은 경로를 밟는다 — 모험 중 전설을 접함 → 호기심 → 계속 찾아다님 → 붕괴.
**플레이어가 하는 짓이 정확히 그 경로다.** 만나는 붕괴자 하나하나가 앞서간 자의 거울이 된다.

### 전설 (뼈대만 확정)

압도적 힘의 불균형 → 우세한 쪽의 극단적 수단 → 대량 사망 → 반환된 정신력은 막대한데 받을 새 생명이 없었다 → 갈 곳 없는 과잉이 **드물게, 예외적으로** 사물에 깃들었다 → 균형이 메워지고 평화 → 전설이 됨.

### 깃든 사물

극히 드물다(세계 전체에 손에 꼽음). 각각이 하나의 인격이자 사건. **대부분의 사람은 실재를 모르고 전설로만 안다.**

### 두 주인공 (구조만 확정)

| | 정체 | 가진 문제 |
|---|---|---|
| A | 깃든 사물 | 왜 존재하는지 모른다. 세상은 나 같은 게 있는 줄도 모른다 |
| B | 생명체 | 알아갈수록 그릇 상한에 가까워진다 |

시드 이미지 — *두 존재가 서로를 쳐다보며 서로의 존재를 물으며 근본을 고민하는 장면.*
단 **"두 로봇"으로 고정하지 않는다.**

### 톤 가드레일 (대사 작성 시 기준)

1. 아무도 "정신이란 무엇인가"를 **입으로 말하지 않는다**
2. 증언은 일상 속에 섞여 나온다
3. 증언이 어긋나는 이유는 음모가 아니라 **무지와 붕괴**
4. **퍼즐 조각처럼 느껴지면 실패** — 추리물이 되는 순간 철학이 주가 된다
5. 목표는 여운. 여운은 진실이 아니라 관계에서 온다

### 참조 작품

`docs/planning/story/STORY_REFERENCES.md` — 메트로배니아 16작의 줄거리 요약. 세계관과 무관하게 유효하므로 리부트 후에도 유지.

## 코드 현황

`src/miji/` — Godot 4 프로젝트. Phase 1~9 구현 완료 (`docs/agents/IMPL_ROADMAP.md`).

| 재사용 가능 | 폐기 대상 |
|---|---|
| `robot.gd` 이동/중력/점프, `camera_follow.gd` | `medium_manager.gd` (매개체·스왑) |
| `attack_hitbox.gd` / `hurtbox.gd` 전투 | `robot.gd`의 스왑 연동부 |

**아직 아무것도 삭제하지 않았다.** 처리 방침은 「다음에 할 일」 4번.

## Agent 구조

- **ORCHESTRATOR** — 요청 분석 → 에이전트 배분 (복합 요청은 병렬 처리)
- **PLANNING** — `docs/planning/` 하위 MD로 기획 관리
- **IMPLEMENTATION** — `src/` 하위 Godot 4 코드. 대형 기능은 `IMPL_REGISTRY.md`에 먼저 등록
- **ART** — Codex 담당. `STYLE_GUIDE.md` + `ART_LOG.md` 기반 OpenAI 프롬프트 생성, 사용자가 ChatGPT에 수동 실행. API 직접 호출 없음

- Stop: 에이전트 역할 체계 리마인더
- PowerShell로 동작. jq 없음, Node.js(v26) 있음. 새 세션 시 자동 활성화 (`/hooks`로 리로드)

### 플러그인
- `superpowers@claude-plugins-official` — 브레인스토밍 등
- `codex@openai-codex` — 아트 프롬프트 일관성

### 새 환경 체크리스트
1. Claude Code 설치
2. `/marketplace` → superpowers 설치
3. `/marketplace` → codex 설치
4. `.claude/settings.json` 확인 (훅 포함 커밋되어 있음 — 별도 설정 불필요)
