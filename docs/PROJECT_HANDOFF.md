## 붙여넣기용 프롬프트

아래 내용을 숙지하고 CLAUDE.md 를 읽은 뒤 작업을 이어가 주세요.

[프로젝트 개요]

- 엔진: Godot 4 / GDScript

- 솔로 개발 프로젝트

---

[Agent 구조]
- ORCHESTRATOR: 요청 분석 → 에이전트 배분
- PLANNING: docs/planning/ 하위 MD 파일로 기획 관리
- IMPLEMENTATION: src/ 하위 Godot 4 코드 구현, 대형 기능은 IMPL_REGISTRY.md에 먼저 등록
- ART: Codex가 담당. STYLE_GUIDE.md + ART_LOG.md 기반으로 OpenAI 프롬프트 생성.
  사용자가 ChatGPT에 수동 실행. API 직접 호출 없음.

---

[핵심 게임 설계 — 확정]

▶ 캐릭터 & 스왑
- 플레이어 = 매개체(Medium). 로봇은 탑승 몸체이자 독립 성격의 캐릭터.
- 두 로봇: 관찰자(철학적) / 행동가(즉흥적). 코드명으로 시작, 스토리 중 이름 획득.
- 스왑: 즉시 전환 + 매개체 이동 시각 연출(~0.5초) + 이전 로봇 취약 구간 존재.
- 비활성 로봇: 그 자리에 완전 정지. 발판/트리거 역할 가능.
- 특정 상황에서 로봇이 자율 행동하는 기믹 있음.

▶ 전투 & 메카닉
- 기본: 근접 공격. 스킬로 원거리/강화 근접 특화.
- 회피: 대쉬 (무적 프레임 없음, 추후 난이도 조율 시 결정)
- 체력: 두 로봇 각각 독립 HP. 어느 쪽 사망해도 게임 오버.
- 회복: 소모 아이템 즉시 회복 + 체크포인트 전체 회복(HP + 자원)
- 자원: 공격 시 충전, 스킬 발동 시 소모 (Hollow Knight 소울 구조). 명칭은 스토리 기획 시 확정.
- 스킬 슬롯: 공격 스킬 1개(최대 2) / 패시브 1→4개 (스토리 진행으로 개방)
- 공격 스킬: 보스 처치 드롭 / 패시브: 탐색 보상 + 일부 보스 드롭

▶ 업그레이드
- 코어 업그레이드: 두 로봇 동시 적용. 메트로배니아 게이트 역할.
  (대쉬 / 이중 점프 / 벽 타기 / 매개체 안정화)
- 특화 업그레이드: 공격력 / 공격속도 / 이동속도 / 최대체력 (로봇별 개별)
- 재화: 공유 풀. 사망 시 현장 드롭, 재방문 회수. 미회수 재사망 시 영구 소실.
- 아이템: 리스크/리워드 트레이드오프 (예: 공격력↑↑ / 받는 데미지↑)

▶ 보스전
- 솔로: 스왑 타이밍으로 패턴 파훼. 빠른 전환이 핵심.
- 코-옵: 두 로봇 동시 행동/포지션 요구 패턴.
- 솔로/코-옵 패턴 별도 설계.
- 보스방 근처 이동수단 배치. 한 로봇만 진입 시 경고 → 무시하면 솔로 패턴 진행.

▶ 세계관
- 세 존재: 매개체 로봇(주인공) / 순수 기계 로봇(적대, 대부분 대화 불가) / 생물체(적대, 대부분 대화 가능)
- 생물체 계층: 일반 생물체 / 부족장(거대, 초반 보스)
- 핵심 미스터리: 매개체의 정체와 기원 (의도적 미확정, 탐색으로 단서 축적)
- 두 로봇은 이유 없이 각성 (창조자 없음, 존재론적 미스터리)

▶ 주요 NPC
- 모험가 생물체: 어리고 호기심 많음. 편견 없이 로봇 접근. 초반 스토리 진입점.
- 수행 로봇: 다리 고장, 어두운 동굴 고립. 매개체 없이 자아 형성. 진중한 성격.

▶ 월드 맵 (MVP 4구역)
- 구조: 순차 연결 + 역추적 지름길
- 배치: 수직 + 수평 혼합
- 시작 구역: 지하 동굴, 튜토리얼, 보스 없음
- 생물체 구역: 지상 좌상단, 넝쿨/독/무너지는 발판, 보스: 부족장
- 폐허 구역: 중앙, 두 세력 격전지, 두 로봇 포지셔닝 퍼즐, 보스: 폐허의 생존자(손상된 대형 기계)
- 기계 구역: 우하단, 레이저/이동 발판/타이밍 기믹, 보스: 기계 군단 수장(최종 보스)
- 풀 스케일: 5~7구역 (바이오메카닉 지대, 매개체 내부 공간 등 추가 예정)

▶ MVP 스토리 흐름 & 결말
지하 동굴 각성 → 모험가 생물체 만남 → 생물체 구역 탐색/부족장 격파
→ 폐허에서 수행 로봇 발견(매개체 첫 단서) → 기계 구역 진입
→ 기계 군단 수장 격파 → 열린 결말 (매개체 정체 미공개)
