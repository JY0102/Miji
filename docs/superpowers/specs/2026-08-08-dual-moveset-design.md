## 0. 발단

사용자 지적 「코어 이동의 당위성은 했나?」 → `MECHANIC_movement.md` 0절 척추가 획득 능력에만 걸려 있었고 각 동작의 세계 내 성립 근거가 없었다. 동시에 갈등 스펙 5절 「결별 = 동행자 시스템 상실」에 구현 수단이 전무함이 드러남 — 이대로면 역추적이 「같은 맵을 슬픈 기분으로 다시 걷기」가 된다.

## 1. 설계 척추 ✅

> **A의 기능** — A가 자기 몸에서 발견한 것. 영구적이다.
> **둘의 동작** — B의 몸이 있어야 성립하는 것. B가 떠나면 사라진다.
>
> 가르는 규칙 한 줄: **A는 스스로 높이를 얻지 못한다.**

「A는 자기 스위치에 손이 안 닿는다」와 같은 계열 — 위로 가는 것도, 켜지는 것도, 꺼지는 것도 전부 **남의 손**이다. 성립 근거는 확정 로어(점화 스펙 「B가 그것을 주웠다」 → A는 들 수 있는 크기). **신규 세계 규칙 0개.**

## 2. 동작 배분 ✅

| # | 소속 | 동작 | 세계 안에서의 성립 | 전투 겸용 |
|---|---|---|---|---|
| F1 | **A** | 돌진 | 기계가 동력을 한 번 짜낸다 | 돌진 공격 |
| F2 | **둘** | **받침** | A가 뛴 정점에서 B가 파고들어 받쳐 한 번 더 올린다 | 공중 견제 |
| F3 | **A** | 부착 이동 | 몸에 달려 있던 기능(형태 TBD) | 벽 기습 |
| F4 | **A** | 강타 | 무거운 기계라 자기 무게가 곧 기능 | 범위기 |
| F5 | **둘** | **투척** | B가 A를 집어 던진다 | A가 발사체 |

⚠️ F5는 「견인/그래플」→「투척」으로 변경 — 같은 게이트(먼 지점)를 열면서 오프닝의 「주웠다」를 회수. 당기기는 A가 능동적이라 척추와 어긋난다.

**B의 손 3회 수미상관:** 오프닝(줍고 켠다) → 여행 내내(받치고 던진다, F2·F5) → 데모 엔딩(끈다).

## 3. B 부재 처리 ✅ — 에스코트 문제 원천봉쇄

**플레이어는 B를 관리하지 않는다. 게임이 B를 항상 제자리에 둔다.**
- 화면 밖 처지면 시야 밖 즉시 복귀(연출 없음)
- 협력 입력 순간 B가 필요한 위치로 스냅 — 「B가 멀어서 못 했다」는 상황을 만들지 않는다. 실패는 오직 조작 실수
- B 무적 유지. 선례: Ori의 Sein, 엘리자베스 계열

## 4. 결별과 재회 ✅

결별 순간 F2·F5 상실. **보상 없음. 목록에서 지우지 않고 잠근다** — 뭘 잃었는지 계속 보게 한다.
- A는 도약으로 높이를 못 얻지만 **기어오를 수는 있다**(F3) → 못 가는 게 아니라 비참하게 간다
- 역추적 구간 설계 제약(지리로 이월): 짧고 좁게, F2·F5 없이 완주 가능, 예전에 B와 넘던 지형은 이제 벽 → 같은 맵이 다른 미로
- 재회 시 그대로 복귀(결별=리허설, 엔딩=본편 위계 유지). 연출은 B가 다시 손을 뻗는 것 하나

## 5. 데모 스코프 ✅ 2026-08-19 승인

> **데모 = 코어 4종(이동·1단점프·근접공격·상호작용) + F1(돌진, A) + F2(받침, 둘).**

2026-08-07 「코어+F1」에서 변경. 근거:
- 기존 스코프에는 협력 동작이 없어 데모가 이원 무브셋 설계를 전혀 못 보여줌. 「B의 손 3회」도 켜고·끄고 사이가 빔
- F2는 협력 동작 중 가장 단순(점프 2회)이라 튜토리얼 비용 ≈ 0
- 비용 = B 협력 AI(스냅 로직)를 데모에서 구현하는 것 하나인데, **본편 전체가 올라탈 시스템이라 세로 슬라이스에서 검증하는 게 맞다**

## 6. 확정 결정 정합성 ✅

- 2026-08-07 「이동 능력은 전부 A의 것」 → **부분 수정.** 당시 근거는 조작감 하나("대쉬 하나에 NPC 부리기")였고 본 설계는 **명령 입력을 만들지 않으므로** 그 근거에 안 걸린다. 「말하기=주기」(플레이어가 B에게 지시)는 여전히 미채택 — 새로 들어오는 것은 「B가 자율 개입하는 물리 동작」이다
- 「B 무적·붕괴 페널티 없음」 유지 / 「스위치는 이동 제외」 유지·강화 / 「능력=소박한 기계 기능」 유지 / 「결별=동행자 시스템 상실」 처음으로 구현 수단 획득 / 「플레이어는 A만 조작」 유지(입력은 전부 A 버튼)
