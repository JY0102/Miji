## 0. 설계 원칙 (사용자 요구의 규칙화)

> **Core = 서사·기획이 바뀌어도 안 바뀌는 것.** 스토리 명사(딸각·무리비·균형자)를 모른다.
> **Gameplay = 기획 문서를 아는 층.** Core 위에 얹히고, 기획이 바뀌면 여기만 바뀐다.
> 의존 방향은 단방향: `Gameplay → Core`. Core는 Gameplay를 참조하지 않는다(이벤트로만 통신).

### Core 분리가 값을 하는 확정 설계 3건

| 확정 설계 | Core에 요구하는 것 |
|---|---|
| 결별 = F2·F5 상실, 「지우지 않고 **잠근다**」 | 능력 시스템이 처음부터 **미획득/해금/잠김 3상태** |
| 2장 = 조작권 인계 (여산→열하나, 반전 방아쇠) | 입력을 PlayerController에 박지 않는다 — **입력 추상화 → 아무 몸에나 꽂는 구조** |
| B는 명령 대상이 아님 — 협력 입력 순간 자율로 붙음 | 명령 큐가 아니라 **이벤트 구독**(EventBus) |

## 1. Core 층 (`Assets/Scripts/Core/`) — 8모듈

| # | 모듈 | 역할 | 근거 |
|---|---|---|---|
| C1 | **EventBus** | 전역 이벤트(능력해금·피격·룸진입·스위치…) | 모든 층의 결합을 끊는 축. 최우선 |
| C2 | **InputReader** | Unity Input System 래핑. 조작 대상 교체 가능 | 2장 조작권 인계·리바인딩·컷신 입력차단 |
| C3 | **StateMachine** | 범용 FSM | 플레이어·적·B·균형자 재사용 |
| C4 | **ProgressionState** | 능력 3상태(미획득/해금/잠김)·진행 플래그·재화 | 결별 메카닉의 토대. 세이브 대상 |
| C5 | **SaveSystem** | 체크포인트·JSON 세이브 | Godot 검증 설계(Phase 7) 재이식 |
| C6 | **GameFlow** | 씬 전환·체크포인트 순서·게임 상태(플레이/컷신/멈춤) | Godot 교훈 「순서는 GameFlow, 데이터는 상태 객체」 승계 |
| C7 | **Combat Core** | Hitbox/Hurtbox·`IDamageable`·콜리전 레이어 피아구분 | Godot 검증 설계(Phase 3) 재이식. 자기피해 가드 포함 |
| C8 | **RoomSystem** | 룸 경계·카메라 제한·룸 전환 | 메트로배니아 뼈대. 구 로드맵에서 밀렸던 것을 Core로 승격 |

## 3. 구현 순서 (세로 슬라이스)

```
1차: C1 → C2 → C3 → C6   뼈대 (이벤트·입력·FSM·흐름)
2차: G1 → C7 → G2         움직이고 때리는 A        ← 첫 조작감 검증 지점
3차: C8 → C4 → C5 → G3    룸·진행·세이브·돌진
4차: G4 → G5              B 동행·협력 (F2)
5차: G6 → G7 → G8 → G9    적·균형자·엔딩·데모 조립
```

- 각 단계 **ULoop 검증 루프** (`uloop compile` / `run-tests` / 플레이모드·스크린샷) — IMPLEMENTATION 표준 작업 방식
- 대형 기능(>1파일 또는 >200줄)은 착수 전 `IMPL_REGISTRY.md` 등록. **Unity 첫 기능 = IMPL-005**
- 구 Godot 로드맵(Phase 1~15)은 참고 이력일 뿐 근거로 삼지 않는다. 재이식 가치 항목(이동 컨트롤러·히트박스·세이브·재화 드롭)은 설계만 참고

## 4. 명시적으로 안 하는 것 (데모 밖)

- F3~F5 (본편 능력) — 단 C4가 3상태를 지원하므로 추가 비용은 데이터뿐
- 그릇 게이지·능력 목록=피해 기록 UI (말하기=주기 계열 — 설계 미확정)
- 전생 기억 트리거 시스템 (본편)
- 맵·구역 실설계 (상류 미결: 깃든 사물 개수·결말) — 데모 룸은 그레이박스
- 붕괴 페널티 (없음이 확정 — B 무적, A는 안 망가짐)

## 5. 리스크 / 열린 것

- **A의 물리적 형태 미정** → 스프라이트·히트박스 크기를 임시(그레이박스 캡슐)로 두고 형태 확정 시 교체
- **균형자 조우 규칙 미확정** (`MECHANIC_movement.md` 7절) → G7은 데모용 스크립트 기습 1회만, 범용 추격 AI는 본편
