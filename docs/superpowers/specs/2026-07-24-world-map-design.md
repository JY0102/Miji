## 2. 공간 배치 (수직 + 수평 혼합)

```
              [ 생물체 구역 ]
              부족 영토, 유기적 환경
              넝쿨·독·무너지는 발판
                    │
                    │ ↑ 위로 올라가며 진입
                    │
[ 시작 구역 ]───────┤
지하 동굴, 중립 지대 │
두 로봇 각성 지점    │
                    │ → 오른쪽으로 이동
                    │
              [ 폐허 구역 ]
              생물체·기계 격전지
              기계 함정 + 생물체 잔해 혼재
                    │
                    │ ↓ 더 깊숙이 진입
                    │
              [ 기계 구역 ]
              순수 기계 로봇 지배 지역
              레이저·이동 발판·타이밍 기믹
```

## 3. 진행 동선 & 지름길

```
[메인 루트]
시작 구역 → 생물체 구역 → 폐허 구역 → 기계 구역

[지름길 1 — 폐허 구역 클리어 후 개방]
생물체 구역 ←──────── 폐허 구역 (역추적 단축)

[지름길 2 — 기계 구역 진입 후 개방]
시작 구역 ←────────────────── 기계 구역 (전체 역추적 단축)
```

## 4. 구역별 상세

### 시작 구역 (Tutorial Zone)
- **위치:** 지하, 맵 중앙 하단
- **분위기:** 어둡고 고요한 동굴. 생물체 구역과 인접.
- **기믹:** 없음 — 기본 이동·전투만 익히는 순수 튜토리얼
- **보스:** 없음
- **역할:** 두 로봇 각성 지점. 스왑 메카닉 튜토리얼.
- **연결:** 생물체 구역(위), 폐허 구역(오른쪽)

---

### 생물체 구역 (Creature Zone)
- **위치:** 지상, 좌상단
- **분위기:** 유기적, 부족 영토. 자연과 생명체가 가득.
- **기믹:** 넝쿨 지형, 독 웅덩이, 무너지는 발판. 수직 이동 중심.
- **주요 적:** 일반 생물체 (대화 가능), 적대적 생물체
- **NPC:** 로봇에 우호적인 생물체 (스토리 진입점)
- **보스:** 부족장
  - 거대한 상위 생물체
  - 일반 생물체와 확연히 다른 몸집과 위압감
  - 솔로 패턴 / 듀오 패턴 별도 구성
- **드롭:** 코어 이동 기술 1개 (이중 점프 또는 대쉬)
- **연결:** 시작 구역(아래), 폐허 구역(오른쪽)

---

### 폐허 구역 (Ruins Zone)
- **위치:** 중앙
- **분위기:** 격전지의 흔적. 기계 잔해와 생물체 흔적이 혼재.
- **기믹:** 기계 함정 + 생물체 잔해. 두 로봇 동시 포지셔닝 퍼즐 중심.
- **주요 적:** 생물체 + 기계 로봇 혼재
- **NPC:** 방치된 깨달음 로봇 (은유적 스토리 힌트 제공)
- **보스:** 폐허의 생존자
  - 전투에서 살아남은 손상된 대형 기계 로봇
  - 손상 부위로 인한 불규칙한 패턴이 특징
  - 솔로 패턴 / 듀오 패턴 별도 구성
- **드롭:** 코어 이동 기술 1개 + 매개체 첫 단서
- **연결:** 생물체 구역(위), 기계 구역(아래), 지름길 1 개방

---

### 기계 구역 (Machine Zone)
- **위치:** 우하단, 가장 깊은 곳
- **분위기:** 산업적, 차갑고 기계적. 순수 기계 로봇의 영역.
- **기믹:** 레이저, 이동 발판, 타이밍 기믹. 정밀한 조작 요구.
- **주요 적:** 순수 기계 로봇 (대부분 대화 불가)
- **NPC:** 없음 (또는 극히 드문 깨달음 로봇)
- **보스:** 기계 군단 수장
  - 가장 고도화된 순수 기계 로봇
  - 냉혹하고 정밀한 전투 패턴
  - MVP 최종 보스
  - 솔로 패턴 / 듀오 패턴 별도 구성
- **드롭:** 코어 이동 기술 1개 + 매개체 핵심 단서
- **연결:** 폐허 구역(위), 지름길 2 개방 (시작 구역까지)

## 6. 체크포인트 배치 원칙

- 각 구역 진입 직후 1개
- 보스방 직전 1개
- 구역 규모에 따라 중간 1~2개 추가
- 지름길 개방 지점 근처 1개

## 7. 풀 스케일 확장 예정 구역 (스토리 기획 후 확정)

| 구역 후보 | 컨셉 |
|----------|------|
| 바이오메카닉 지대 | 기계와 유기체가 융합된 중간 지대 |
| 매개체 내부 공간 | 매개체 기원 공개. 디지털/초현실적 환경 |
| 기타 | 스토리 기획 단계에서 결정 |

## 미확정 항목

- 각 구역의 룸 수 (레벨 디자인 단계에서 확정)
- 보스 구체적 패턴 (메카닉 상세 기획 단계)
- 지름길 정확한 위치 (레벨 디자인 단계)
- 코어 이동 기술 획득 순서 (대쉬 vs 이중 점프 중 어느 것이 먼저인지)
- 풀 스케일 추가 구역 2~3개 상세 내용
