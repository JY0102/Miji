## 1. 플레이어 정체성

- **플레이어 = 매개체(Medium)**
- 두 로봇은 플레이어(매개체)가 탑승하는 몸체이자 독립적 성격을 가진 캐릭터
- 로봇의 대화와 반응이 스토리를 전달하는 주요 장치

---

## 2. 주인공 — 두 로봇

### 공통 설정
- 시작 시 코드명(기계적 일련번호)으로만 존재
- 스토리 진행 중 NPC 또는 서로에게서 이름을 얻음
- **이름을 얻는 순간 = 존재로 인정받는 서사적 비트**
- 기계의 단단함·잔혹성 + 생물체의 따뜻함을 동시에 가짐

### 로봇 1 — 관찰자 (코드명 미정)
- **성격:** 분석적, 철학적. 세계와 자신을 끊임없이 관찰하고 질문함
- **대화 스타일:** "우리 안의 것은 무엇인가. 왜 우리만 이것을 가지는가."
- **역할:** 매개체의 본질에 대한 의문을 대사로 끌어냄
- **행동 방식:** 상황을 먼저 파악하고 움직임

### 로봇 2 — 행동가 (코드명 미정)
- **성격:** 즉흥적, 직관적. 생각보다 행동이 먼저
- **대화 스타일:** "생각은 나중에. 지금은 앞으로."
- **역할:** 관찰자의 철학적 질문에 현실적·감정적으로 반응
- **행동 방식:** 일단 움직이고 이후에 판단

### 두 로봇의 관계
```
관찰자: "우리가 존재하는 이유가 있을까?"
행동가: "있든 없든, 지금 여기서 움직여야 해."
          ↓
  서로의 질의응답이 매개체의 본질 탐구를 이끄는 내러티브 엔진
```

## 3. 주요 NPC

### 모험가 생물체
- **역할:** 초반 스토리 진입점. 생물체 구역 근처 또는 시작 구역 경계에서 등장
- **성격:** 어리고 호기심 많음. 종족의 로봇 적대감과 무관하게 순수한 호기심으로 접근
- **기능:**
  - 세계관 초입 안내 (생물체 구역 정보, 부족 구조 설명)
  - 가벼운 분위기로 무거운 세계관 환기
  - 로봇과 생물체가 공존할 수 있다는 가능성 암시
- **부족 내 포지션:** 이단아 또는 아직 선입견이 없는 어린 개체

### 수행 로봇 (깨달음의 기계)
- **위치:** 폐허 구역 또는 구역 경계의 어두운 동굴
- **상태:** 다리 고장으로 이동 불가. 오랜 시간 홀로 고립
- **성격:** 진중하고 차분함. 말이 많지 않지만 무게감 있음
- **배경:**
  - 본래 순수 기계 로봇으로 생물체를 의미 없이 적대했음
  - 고장 후 혼자 남겨져 오랜 시간 자신의 존재를 사유
  - 매개체 없이 스스로 자아를 형성한 존재
- **서사적 의미:**
  - "매개체 없이도 자아가 생길 수 있다면, 매개체란 무엇인가?"
  - 매개체의 본질에 대한 가장 중요한 단서를 품고 있음
- **대화 방식:** 직접적이지 않지만 명확한 통찰. 스님처럼 질문으로 질문에 답함

## 4. 중심 미스터리

**매개체(Medium)란 무엇인가?**

| 항목 | 내용 |
|------|------|
| 현재 상태 | 의도적으로 미확정 |
| 단서 제공자 | 수행 로봇, 폐허 구역 흔적, 기계 군단 수장 처치 후 |
| MVP 내 공개 범위 | 단서만 제공, 정체는 미공개 |
| 풀 스케일에서 확정 | 스토리 기획 심화 단계 |

**핵심 질문들 (탐색을 통해 쌓이는 의문)**
- 왜 두 로봇만 매개체를 가지는가?
- 수행 로봇은 매개체 없이 어떻게 자아를 얻었는가?
- 순수 기계 로봇은 왜 매개체를 가진 존재를 적대하는가?
- 생물체와 기계의 충돌은 매개체와 관련이 있는가?

## 5. MVP 스토리 흐름

```
[시작 — 지하 동굴]
두 로봇, 이유 없이 눈을 뜸
서로를 인식하고 매개체의 존재를 감지
목표 없이 출구를 향해 이동 시작

      ↓

[생물체 구역]
모험가 생물체와 첫 접촉
세계의 구조(생물체 vs 기계)를 처음으로 인식
부족장 격파 → 첫 코어 이동 기술 획득
관찰자와 행동가, 첫 번째 철학적 대화

      ↓

[폐허 구역]
격전지의 흔적 — 세계의 역사를 목격
수행 로봇 발견 → 매개체에 대한 첫 번째 핵심 단서
"매개체 없이 자아를 얻은 존재가 있다"
폐허의 생존자 격파

      ↓

[기계 구역]
순수 기계 로봇 세계의 실체를 마주함
기계 군단 수장 격파
처치 직전 또는 직후 — 수장이 매개체를 인식하고 반응
새로운 의문이 열림

      ↓

[열린 결말]
매개체의 정체는 밝혀지지 않음
두 로봇은 더 많은 질문을 가진 채 앞으로 나아감
"우리가 무엇인지는 모른다. 하지만 우리는 여기 있다."
```

## 6. 네이밍 이벤트 (스토리 비트)

이름을 얻는 순간은 단순한 명명이 아닌 **존재 인정의 서사적 순간**으로 설계.

| 이벤트 | 제안 타이밍 |
|--------|-----------|
| 로봇 1 이름 획득 | 수행 로봇과의 대화 중 (폐허 구역) |
| 로봇 2 이름 획득 | 모험가 생물체가 붙여줌 (생물체 구역) |

*구체적 이름은 세부 스토리 기획 단계에서 확정*

---

## 7. 톤 & 분위기

- **무겁지만 따뜻함** — 존재론적 질문을 다루지만 희망을 잃지 않음
- **대화 중심 내러티브** — 두 로봇의 대화가 세계관과 미스터리를 자연스럽게 전달
- **NieR:Automata 참조** — 기계와 감정, 존재의 의미를 탐구하는 톤
