# 코어 컨셉 디자인 스펙
**날짜:** 2026-07-24  
**상태:** 확정  
**다음 단계:** 코어 메카닉 기획 → 월드 맵 구조 기획 → 스토리 & 캐릭터 기획

---

## 1. 장르 & 플레이 모드

| 항목 | 내용 |
|------|------|
| 장르 | 메트로배니아 |
| 플레이어 수 | 1인 (솔로) / 2인 협동 (코-옵) |
| 솔로 방식 | 매개체로 두 로봇을 번갈아 조종 |
| 코-옵 방식 | 각 플레이어가 하나의 로봇 전담 |

---

## 2. 플레이어 정체성

- **플레이어 = 매개체(Medium)** — 스토리상 "나"는 매개체 자체. 로봇은 탑승하는 몸체.
- **로봇은 독립적 성격**을 가진 캐릭터 — 매개체(플레이어)와 별개로 반응하고 판단함.
- **자율 행동 기믹** — 특정 상황에서 로봇이 스스로 움직임. 플레이어 의도와 로봇 성격이 충돌하는 연출 가능.

---

## 3. 스왑 메카닉

| 단계 | 동작 |
|------|------|
| 스왑 입력 | 즉시 조작권 전환 (딜레이 없음) |
| 연출 | 매개체가 두 로봇 사이를 이동하는 시각 이펙트 (~0.5초) |
| 이전 로봇 | 연출 구간 동안 취약(피격 가능), 이후 완전 정지 |
| 정지 로봇 | 발판·스위치 트리거 등 퍼즐 요소로 기능 |

**솔로 vs 코-옵 차이**

| 모드 | 특징 |
|------|------|
| 솔로 | 스왑 타이밍이 핵심 긴장 요소. 매개체 이동 중 취약 구간 존재 |
| 코-옵 | 스왑 없음. 협력·포지셔닝 중심 |

---

## 4. 보스전

| 모드 | 패턴 방향 |
|------|----------|
| 솔로 | 스왑 타이밍으로 패턴 파훼 가능. 빠른 전환이 공략 핵심 |
| 코-옵 | 두 로봇의 동시 행동·포지션을 요구하는 패턴 |

솔로와 코-옵의 보스 패턴은 별도로 설계. 두 모드 모두 고유한 플레이 경험 제공.

---

## 5. 세계관 & 존재 구조

### 세 종류의 존재

| 존재 | 특성 | 대화 | 역할 |
|------|------|------|------|
| **매개체 로봇** (주인공) | 기계의 단단함·잔혹성 + 생물체의 따뜻함 | 가능 | 플레이어. 양쪽 어디에도 속하지 않음 |
| **순수 기계 로봇** | 완전한 기계. 냉혹·감정 없음 | 대부분 불가 | 생물체와 적대. 중후반 주요 적 |
| **생물체** | 유기 존재. 부족 단위 사회 | 대부분 가능 | 로봇과 적대. 초반 주요 적 |

### 생물체 계층

```
일반 생물체   — 대화 가능, 일반 적
     ↓
부족장 / 상위 생물체 — 거대한 몸집, 초반 지역 보스
```

### 세계 긴장 구도

```
순수 기계 로봇  ←── 적대 ──→  생물체
                       ↑
           주인공 (어디에도 속하지 않음)
           매개체의 정체가 이 구도를 바꿀 열쇠
```

### NPC 구성

**① 방치된 상위 로봇 (깨달음의 로봇)**
- 말할 수 있는 드문 기종. 고장 상태로 외딴 지역에 방치됨
- 은유와 독백으로 매개체·세계에 대한 단편적 힌트 제공
- 재방문 시 새로운 대사 추가 가능

**② 로봇에 우호적인 생물체**
- 로봇에 관심 또는 과거 유대가 있는 소수 개체
- 초반 스토리 진입점 역할. 부족 내 이단아 포지션

## 6. 스토리 구조

**중심 미스터리:** 매개체(Medium)의 정체와 기원

```
[시작]  두 로봇, 자신들 안의 매개체를 인식
   ↓
[탐색]  세계를 돌며 매개체와 유사한 존재·흔적 발견
   ↓
[반전]  순수 기계 로봇 / 생물체와의 관계에서 매개체 기원 단서
   ↓
[결말]  매개체의 정체 완전 공개 (스토리 기획 단계에서 확정)
```

## 7. 업그레이드 시스템

### 트리 구조

| 레이어 | 대상 | 역할 |
|--------|------|------|
| **코어 업그레이드** | 두 로봇 동시 적용 | 새 구역 진입 조건 (메트로배니아 게이트) |
| **특화 업그레이드** | 로봇별 개별 선택 | 플레이 스타일 커스터마이징 |

### 코어 업그레이드 예시

```
대쉬 / 이중 점프 / 벽 타기 / 매개체 안정화
```

### 특화 업그레이드 (4종 고정)

| 스탯 | 설명 |
|------|------|
| 공격력 | 기본 데미지 증가 |
| 공격 속도 | 타격 빈도 증가 |
| 이동 속도 | 이동·탐색 속도 증가 |
| 최대 체력 | 생존력 증가 |

### 아이템 시스템 (리스크/리워드)

아이템은 스탯을 강화하되 트레이드오프를 동반함.

| 아이템 예시 | 효과 |
|------------|------|
| 폭주 코어 | 공격력 ↑↑ / 받는 데미지 ↑ |
| 경량 프레임 | 이동속도 ↑↑ / 최대 체력 ↓ |
| 과부하 엔진 | 공격속도 ↑↑ / 이동속도 ↓ |

두 로봇에 아이템을 다르게 장착 → 자연스러운 역할 분담.

## 8. 세계 진행 구조

```
[초반] 생물체 구역
 → 부족 일반 적 + 부족장 보스
 → 코어 업그레이드 1~2개 획득
 → 우호적 생물체 NPC 등장, 스토리 진입

[중반] 폐허 / 기계 구역
 → 순수 기계 로봇 등장
 → 방치된 깨달음 로봇 NPC 발견
 → 매개체 관련 첫 단서

[후반] 바이오메카닉 + 내부 공간
 → 두 세력의 충돌 지점
 → 매개체의 기원 공개
```
