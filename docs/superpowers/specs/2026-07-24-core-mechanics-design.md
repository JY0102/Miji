## 1. 전투 시스템

### 기본 공격
- 두 로봇 모두 **근접 공격 기반**
- 스킬을 통해 **원거리** 또는 **강화 근접**으로 특화 가능

### 회피
- **대쉬만 존재** — 무적 프레임 없음
- 순수 포지셔닝으로 회피
- 난이도 조율 후 무적 여부 추후 결정

### 체력
- 두 로봇 **각각 독립 HP**
- 어느 쪽이든 사망 시 **게임 오버**
- 즉시 회복: 탐색·드롭으로 획득한 **소모 아이템** 사용
- 전체 회복: **체크포인트 도착 시** 두 로봇 HP + 자원 모두 회복

---

## 2. 자원 시스템 (Hollow Knight 구조 차용)

```
적 공격 시 → 자원 충전
자원 소모  → 스킬 발동 (쿨다운 병행)
체크포인트 → 자원 풀충전 + 두 로봇 HP 전체 회복
```

- 자원 명칭·설정은 **스토리 기획 단계에서 확정**
- 체크포인트 기능: 세이브 + 자원 풀충전 + 두 로봇 HP 전체 회복

---

## 3. 스킬 시스템

### 슬롯 구성

| 슬롯 종류 | 시작 | 최대 | 획득 방식 |
|----------|------|------|----------|
| **공격 스킬 (Active)** | 1개 | 1~2개 | 보스 처치 드롭 |
| **패시브 (Passive)** | 1개 | 4개 | 탐색 보상 + 일부 보스 드롭 |

*공격 스킬 슬롯 +1 여부는 스토리 진행 중 결정*

### 슬롯 성장

```
게임 시작  → 공격 스킬 1 / 패시브 1
스토리 중반 → 공격 스킬 1 / 패시브 2~3
스토리 후반 → 공격 스킬 1~2 / 패시브 4 (최대)
```

### 공격 스킬 (Active)
- 강력한 공격기 또는 원거리기
- 자원 소모 + 쿨다운으로 발동
- 보스 처치 시 획득

### 패시브 (Passive)
- 스탯 변화, 행동 변화, 트레이드오프 효과
- Hollow Knight 참(Charm) 시스템과 유사한 조합 다양성
- 두 로봇에 **각각 독립 장착** → 역할 분담 가능

## 4. 이동 & 메트로배니아 게이트

### 코어 이동 기술 (두 로봇 동시 적용)

| 기술 | 게이팅 역할 |
|------|-----------|
| 대쉬 | 기본 이동, 초반 획득 |
| 이중 점프 | 수직 탐색 게이트 |
| 벽 타기 | 수직 탐색 심화 게이트 |
| 매개체 안정화 | 특정 구역 진입 조건 (설정 연계) |

### 두 로봇 포지셔닝
- 구역마다 규칙이 다름
- 선발대 로봇이 먼저 진입해 길을 열고, 후발 로봇이 따라오는 구조 혼용
- 솔로: 정지 로봇을 발판·트리거로 활용하는 퍼즐 설계

### 보스방 진입 시스템

```
보스방 근처에 이동수단 배치 (두 번째 로봇 합류 가능)
          ↓
      [진입 시도]
      ┌─────────────────────────────┐
      │ 두 로봇 모두 있음            │→ 듀오 패턴 보스전
      │ 한 로봇만 있음              │→ 경고 메시지 표시
      └─────────────────────────────┘
                    ↓
         경고 무시하고 진입 → 솔로 패턴 보스전
         돌아가기          → 두 번째 로봇 합류 후 재시도
```

## 5. 업그레이드 & 진행 구조

### 특화 업그레이드 (4종, 로봇별 개별 적용)

| 스탯 | 설명 |
|------|------|
| 공격력 | 기본 데미지 증가 |
| 공격 속도 | 타격 빈도 증가 |
| 이동 속도 | 이동·탐색 속도 증가 |
| 최대 체력 | 생존력 증가 |

### 재화 시스템

| 항목 | 내용 |
|------|------|
| 획득 | 적 처치 + 탐색 |
| 저장 | 두 로봇 **공유 풀** |
| 사용 | 업그레이드 스테이션 — 적용 로봇 선택 후 소모 |
| 사망 시 | 사망 지점에 전액 드롭 |
| 회수 | 해당 위치 재방문으로 회수 가능 |
| 미회수 | 재사망 시 영구 소실 |

### 아이템 시스템 (리스크/리워드)

| 아이템 예시 | 효과 |
|------------|------|
| 폭주 코어 | 공격력 ↑↑ / 받는 데미지 ↑ |
| 경량 프레임 | 이동속도 ↑↑ / 최대 체력 ↓ |
| 과부하 엔진 | 공격속도 ↑↑ / 이동속도 ↓ |

### 전체 진행 흐름

```
[초반]
스킬 1개 / 패시브 1개 / 코어 이동 기술 없음
→ 생물체 구역 탐색
→ 부족장 보스 처치 → 첫 코어 이동 기술 획득
→ 우호적 생물체 NPC, 스토리 진입

[중반]
스킬 1개 / 패시브 2~3개 / 코어 이동 기술 2개
→ 기계 구역 진입, 순수 로봇 등장
→ 방치된 깨달음 로봇 NPC
→ 매개체 첫 단서 발견

[후반]
스킬 1~2개 / 패시브 4개 / 코어 이동 기술 전부
→ 바이오메카닉 + 내부 공간
→ 두 세력 충돌 지점
→ 매개체 기원 공개
```
