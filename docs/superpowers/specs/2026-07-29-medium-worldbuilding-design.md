## 1. 매개체의 정체 (작가용 정답)

플레이어에게는 MVP 내내 숨긴다. 단서만 뿌린다.

| 항목 | 확정 내용 |
|------|----------|
| 분류 | **유물** — 선행 문명(=사람)이 남긴 것 |
| 물성 | **에너지.** 생명체가 아니다 |
| 시각 | 작고 빛나며 떠다니는 입자. **반딧불이는 시각 레퍼런스일 뿐 게임 내 명칭이 아니다** |
| 의지 | **없다.** 의지는 플레이어가 넣는다 |
| 기능 | **동력이다. 의지가 아니다** |
| 희소성 | 극히 드묾 |

### 가장 중요한 한 줄

> **매개체는 몸에 동력을 준다. 인격은 로봇 자신의 것이다.**

이 한 줄에서 나오는 것들:

- 매개체가 **들어온 몸** — 온전히 움직인다
- 매개체가 **나간 몸** — 인격은 깨어 있으나 몸이 굳는다. **말은 할 수 있다**
- 얼개·온기의 성격은 매개체와 무관하게 존재한다 (기존 스펙의 "독립적 성격"이 이제 근거를 가짐)
- 두 로봇의 대화가 내러티브 엔진이라는 기존 설계가 **비로소 성립한다** — 이전 설정("비활성 로봇은 완전 정지")으로는 둘이 어떻게 대화하는지 설명할 수 없었다

### 수행 로봇과의 연결 (중요)

수행 로봇 = **인격은 온전한데 몸이 안 움직이는 존재**.

두 주인공이 스왑할 때마다 잠깐씩 겪는 상태를, 수행 로봇은 **영원히** 겪고 있다.
"매개체 없이 자아를 형성했다"가 우연이 아니라 **같은 원리의 극한**이 된다.
매개체의 본질에 대한 가장 중요한 단서라는 기존 역할이 그대로 유지되면서, 근거가 생겼다.

## 2. 세계의 역사 — 전쟁의 기원

```
① 사람 vs 생명체 전쟁
   일부 강한 생명체가 사람을 압도. 사람이 밀린다
              ↓
② 사람, 대항 병기로 로봇을 제작
              ↓
③ 로봇은 생명체를 "구분하지 않고" 전부 적대   ← ★ 분류 실패
              ↓
④ 중립이던 대다수 생명체까지 로봇을 미워하게 됨
              ↓
⑤ 악순환 → 오늘의 전쟁
```

### ③이 이 세계관의 핵심이다

순수 기계 로봇의 잔혹함은 **"감정이 없어서"가 아니라 "명령이 아직 실행 중이라서"**다.

- 전쟁의 원인은 악의가 아니라 **범주 오류**다
- 적대적이지 않던 생물체까지 적으로 분류한 것이 전쟁을 만들었다
- 이건 게임 톤("무겁지만 따뜻함")과 정확히 맞고, 플레이어가 그 분류의 바깥에 서 있다는 점에서 주인공 포지션과도 맞는다

### 사람의 현재

**부재.** 언제·왜 사라졌는지는 미확정 (→ §5 열린 질문).

|---|---|

| 세 존재 (매개체 로봇 / 순수 기계 / 생물체) | 유지. **사람은 과거의 4번째 층위**로 추가 |

## 4. 메카닉으로의 귀결

설정이 게임 규칙을 직접 결정한 부분. 구현 시 이 절이 기준이다.

### 4.1 스왑

| 규칙 | 값 | 근거 |
|---|---|---|
| 사정거리 | **제한 없음** | 맵 어디에 있는 몸으로든 건너간다 |
| 비용 | **무료** | 에너지를 소모하지 않는다 |
| 연출 | 매개체가 물리적으로 날아간다 | **이미 구현됨** — `src/miji/scripts/medium_manager.gd`의 `_orb` (0.5초 트윈). 아트만 붙이면 됨 |

### 4.2 두 번째 몸 = 순간이동 앵커 ★

사정거리 제한이 없으므로, **멀리 세워둔 몸으로 건너가는 것이 곧 순간이동**이다.
설정을 새로 만들 필요가 없다.

```
로봇 B를 갈림길·체크포인트에 세워둔다   ←── 앵커
              ↕  스왑 = 순간이동
로봇 A로 위험한 갈래를 탐험한다          ←── 첨병
```

**앵커는 하나뿐**이다 (몸이 둘뿐이므로). 새 지점에 앵커를 심으려면 그 몸으로 직접 가야 하고,
그 순간 이전 앵커는 사라진다. **별도 제약 규칙 없이 밸런스가 잡힌다.**

> 이 시스템이 해결한 문제: 메트로배니아는 역추적이 장르의 절반인데, 두 몸을 항상 끌고
> 다니면 모든 이동이 2배가 된다. 두 번째 몸이 **짐이 아니라 이동 수단**이 되면서 해소됨.

### 4.3 자율 이동

맵에서 **이미 방문한 지점**을 지정하면 로봇이 스스로 걸어간다.

| 항목 | 규칙 |
|---|---|
| 근거 | 매개체가 없어도 몸에 남은 잔여 동력으로 단순 이동은 가능 |
| 대상 | **방문한 지점만** — 잔여 동력으로는 새 길을 개척 못 함 |
| 속도 | 실시간으로 느리게 이동. 즉시 도착 아님 |
| 비용 | **시간** (재화도 에너지도 아님) |
| 도중 스왑 | 그 시점의 위치로 간다 |

### 4.4 근거리에서는 기존 설계 전부 유지

정지 로봇 발판화 / 폐허 구역 두 몸 포지셔닝 퍼즐 / 보스 듀오 패턴 / 코-옵 — 모두 그대로.
스왑은 **근거리에선 퍼즐·전투 전환, 원거리에선 순간이동**이라는 두 겹의 용도를 갖는다.

### 4.5 튜토리얼 (시작 구역) 구조

```
지하 동굴 — 매개체가 로봇 A 안에서 눈을 뜬다
            (스왑 없음. 이동·공격만. 조작권이 하나뿐)
                     ↓
        방치된 채 정지해 있는 로봇 B를 발견
                     ↓
        매개체가 건너간다 = 첫 스왑, 로봇 B 각성
        ★ 플레이어가 "내가 로봇이 아니라 그 안의 것"임을 처음 깨닫는 순간
                     ↓
        두 몸을 오가는 것이 전진 수단이 된다
```

시작 구역이 "기믹 없음, 순수 튜토리얼, 보스 없음"이라는 기존 정의와 일치하며,
스왑 메카닉 튜토리얼이 **서사적 사건**과 같은 지점에서 일어난다.

### 4.6 타이틀 화면 = 디에게시스

- 메뉴 뒤에 매개체가 떠돈다 (사실은 **몸 없이 방전되어 가는 중**)
- 게임 시작 → 매개체가 로봇에게 들어가는 애니메이션
- 플레이어는 "게임을 시작"하는 게 아니라 **매개체가 몸을 고르는** 것
- 세이브/재시작 = 다시 떠도는 상태로 돌아감

### 4.7 코-옵

매개체 2개 (플레이어 1인당 1개). 앵커·순간이동 개념이 필요 없고,
기존 스펙의 "코-옵 = 협력·포지셔닝 중심"이 그대로 유지된다.
